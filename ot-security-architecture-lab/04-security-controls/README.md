# Phase 4 — Defensive engineering and control validation (planned)

Start from the phase 1 and 3 baseline. Prepare a change request, control objective, scope, implementation plan and rollback criteria. Apply one control at a time (access segmentation, endpoint hardening, least privilege, or monitoring). Demonstrate intended traffic still functions and disallowed traffic is blocked, while tracking process availability. Record before/after data and actual firewall/ACL rules if safe to publish.
